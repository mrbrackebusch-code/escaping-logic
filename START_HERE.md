# Escaping Logic

Escaping Logic is delivered as one MakeCode Arcade project with one initial setup tutorial and five in-context room Recipes. The setup creates the project once. Later room links are Recipes and are intended to operate against the learner's current code in that same project.

## Start

[Open the one-time setup](https://arcade.makecode.com/?nocdn=1&skipgithubcache=1#tutorial:https://github.com/mrbrackebusch-code/escaping-logic/docs/tutorials/escaping-logic-setup)

## Room Recipes

- Room A — Workshop
- Room B — Light Gallery
- Room C — Garden Room
- Room D — Bridge Room
- Room E — Last Door

If you are returning later, reopen your existing **logic-escape-room** project and use the room links inside its tutorial. Setup creates a new project.

This release is available for owner review. Engineering verification does not establish human classroom acceptance or learning outcomes.
